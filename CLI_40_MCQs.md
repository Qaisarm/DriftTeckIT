# Command-Line Interface (CLI) -- MCQ

Baserat på filen **"Övning Command-Line Interface (CLI)"**.

## Flervalsfrågor

A)  Command-Line Interface\
B)  Computer Link Interface\
C)  Command Level Internet\
D)  Control Line Input

### 2. Vilket av följande är en användning av CLI enligt materialet?

A)  Diagnostisera problem\
B)  Designa grafiska ikoner\
C)  Redigera bilder\
D)  Spela upp video

A)  Konfigurera system och automatisera uppgifter\
B)  Bygga hårdvara automatiskt\

D)  Ändra skärmens storlek fysiskt

A)  Det kan ge detaljerad information som inte alltid finns i grafiska
    gränssnitt\

C)  Det ersätter alltid operativsystemet\

A)  cmd eller PowerShell\
B)  Paint eller Word\
C)  BIOS eller UEFI\
D)  Task Manager eller CPU-Z

C)  Endast användarkonton\
D)  Endast öppna portar

C)  Användarhantering\
D)  Batteridiagnostik

A)  Testar anslutningen till en annan dator eller server\
B)  Visar alla filer\

D)  Skapar en användare
