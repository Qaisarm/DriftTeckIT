# Windows 11 Keyboard Shortcuts -- MCQ

Baserat på filen **"Windows 11 Keyboard Shortcuts Cheat Sheet"**.

## Flervalsfrågor

### 1. Vad används Alt + Tab till?

**A)  Växla snabbt mellan öppna fönster och appar**\
B)  Öppna Inställningar\
C)  Låsa datorn\
D)  Öppna Aktivitetshanteraren

### 2. Vad gör Windows + D?

A)  Öppnar File Explorer\
**B)  Visar skrivbordet och minimerar alla fönster**\
C)  Öppnar Search\
D)  Låser datorn

### 3. Vad händer om du trycker Windows + D igen efter att skrivbordet visats?

A)  Datorn stängs av\
**B)  Alla fönster återställs**\
C)  Aktivitetshanteraren öppnas\
D)  File Explorer öppnas

### 4. Vilken genväg låser datorn direkt?

**A)  Windows + L**\
B)  Windows + D\
C)  Windows + I\
D)  Alt + F4

### 5. Vilken genväg öppnar File Explorer?

**A)  Windows + E**\
B)  Windows + F\
C)  Windows + X\
D)  Windows + R

### 6. Vilken genväg öppnar Settings/Inställningar?

A)  Windows + A\
**B)  Windows + I**\
C)  Windows + S\
D)  Windows + P

### 7. Vad öppnar Windows + A?

**A)  Quick Settings**\
B)  Aktivitetshanteraren\
C)  File Explorer\
D)  Task View

### 8. Vilka funktioner kan finnas i Quick Settings enligt materialet?

**A)  Wi-Fi, Bluetooth och Brightness**\
B)  CPU, RAM och GPU\
C)  Filer, mappar och diskar\
D)  Användare, grupper och tjänster

### 9. Vad gör Windows + S?

**A)  Öppnar Search**\
B)  Öppnar Settings\
C)  Stänger aktuellt program\
D)  Låser datorn

### 10. Vad kan du hitta med Windows + S?

**A)  Appar, filer eller webbinnehåll**\
B)  Endast bilder\
C)  Endast Windows-tjänster\
D)  Endast nätverkskort

### 11. Vad gör Windows + V?

**A)  Öppnar Clipboard history**\
B)  Öppnar Virtual Desktop\
C)  Öppnar Volume Settings\
D)  Öppnar Task View

### 12. Vad krävs för att Windows + V ska kunna visa Clipboard history?

**A)  Funktionen måste vara aktiverad i Settings**\
B)  Datorn måste startas om\
C)  Bluetooth måste vara aktiverat\
D)  File Explorer måste vara öppet

### 13. Vilken genväg startar Snipping Tool för skärminspelning/skärmbild?

**A)  Windows + Shift + S**\
B)  Windows + Shift + M\
C)  Windows + S\
D)  Alt + Shift + S

### 14. Vad används Windows + . (punkt) till?

**A)  Öppna emoji-väljaren**\
B)  Öppna Settings\
C)  Öppna Search\
D)  Öppna Task Manager

### 15. Vilken genväg öppnar Aktivitetshanteraren direkt?

**A)  Ctrl + Shift + Esc**\
B)  Ctrl + Alt + Esc\
C)  Windows + Esc\
D)  Alt + Tab

### 16. Vad gör Alt + F4?

**A)  Stänger aktuellt fönster eller program**\
B)  Öppnar Settings\
C)  Öppnar Search\
D)  Skapar ett nytt virtuellt skrivbord

### 17. Vad händer med Alt + F4 när du befinner dig på skrivbordet?

**A)  Den öppnar avstängningsdialogen**\
B)  Den öppnar File Explorer\
C)  Den låser datorn\
D)  Den öppnar Quick Settings

### 18. Vad gör Windows + M?

**A)  Minimerar alla fönster**\
B)  Maximerar alla fönster\
C)  Skapar ett virtuellt skrivbord\
D)  Öppnar Task View

### 19. Vad gör Windows + Shift + M?

**A)  Återställer alla minimerade fönster**\
B)  Minimerar alla fönster\
C)  Stänger alla fönster\
D)  Öppnar Snap Layouts

### 20. Vad gör Windows + P?

**A)  Öppnar display/project-alternativ**\
B)  Öppnar Clipboard history\
C)  Öppnar Search\
D)  Öppnar Aktivitetshanteraren

### 21. Vilket är ett exempel på display/project-alternativ?

**A)  Duplicate eller Extend**\
B)  Copy eller Paste\
C)  Start eller Stop\
D)  Lock eller Unlock

## Del 2: Virtuella skrivbord

### 22. Vad används virtuella skrivbord till enligt materialet?

**A)  Organisera olika uppsättningar av fönster efter uppgift eller**
    projekt\
B)  Öka datorns RAM\
C)  Installera appar\
D)  Ändra skärmens ljusstyrka

### 23. Vilken genväg skapar ett nytt virtuellt skrivbord?

**A)  Windows + Ctrl + D**\
B)  Windows + D\
C)  Windows + Ctrl + N\
D)  Ctrl + Shift + D

### 24. Hur växlar man mellan virtuella skrivbord?

**A)  Windows + Ctrl + vänster/höger pil**\
B)  Windows + vänster/höger pil\
C)  Alt + vänster/höger pil\
D)  Ctrl + vänster/höger pil

### 25. Vad öppnar Windows + Tab?

**A)  Task View för att hantera skrivbord och appar**\
B)  Settings\
C)  File Explorer\
D)  Clipboard history

## Del 3: Snap Window Shortcuts

### 26. Vad gör Windows + vänsterpil?

**A)  Fäster fönstret till vänstra halvan av skärmen**\
B)  Flyttar fönstret till ett annat skrivbord\
C)  Minimerar fönstret\
D)  Stänger fönstret

### 27. Vad gör Windows + högerpil?

**A)  Fäster fönstret till högra halvan av skärmen**\
B)  Maximerar fönstret\
C)  Öppnar Snap Layouts\
D)  Stänger fönstret

### 28. Vad gör Windows + uppåtpil?

**A)  Maximerar eller fäster fönstret till den övre halvan**\
B)  Flyttar fönstret åt vänster\
C)  Minimerar fönstret\
D)  Öppnar Task View

### 29. Vad gör Windows + nedåtpil?

**A)  Minimerar eller fäster fönstret till den nedre halvan**\
B)  Öppnar Settings\
C)  Flyttar fönstret till höger\
D)  Skapar ett virtuellt skrivbord

### 30. Vad öppnar Windows + Z?

**A)  Snap Layouts-menyn**\
B)  Search\
C)  Quick Settings\
D)  Task Manager

### 31. Vad är syftet med Snap Window Shortcuts?

**A)  Multitasking och organisering av skärmen**\
B)  Hantering av användarkonton\
C)  Nätverksdiagnostik\
D)  Installation av Windows

### 32. Vilken genväg passar bäst om du vill snabbt växla mellan flera öppna appar?

**A)  Alt + Tab**\
B)  Windows + L\
C)  Windows + E\
D)  Windows + Z

### 33. Vilken genväg passar bäst om du vill snabbt låsa datorn?

**A)  Windows + L**\
B)  Windows + D\
C)  Windows + M\
D)  Alt + F4

### 34. Vilken genväg passar bäst om du vill snabbt öppna File Explorer?

**A)  Windows + E**\
B)  Windows + F\
C)  Windows + X\
D)  Windows + Tab

### 35. Vilken genväg passar bäst om du vill ta en del av skärmen som skärmbild?

B)  Windows + Shift + M\
C)  Windows + S\
D)  Windows + P
